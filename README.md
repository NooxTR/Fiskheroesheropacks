# ⚡ FiskHeroes Heropack

A custom Heropack made for the **FiskHeroes** Minecraft mod.

This project adds custom characters, abilities, textures and more to FiskHeroes.

> 🚧 This project is currently in development.

---

## ✨ Features

- 🦸 Custom characters
- ⚡ Custom abilities
- 👊 Unique powers and attacks
- 🎨 Custom textures
- 🚀 Flying abilities
- 🔥 Custom effects and animations
- 🛠️ More characters planned

---

## 📦 Requirements

Before installing the Heropack, make sure you have:

- Minecraft **1.7.10**
- **FiskHeroes 2.4.0**
- Forge

---

## 📥 Installation

1. Download the latest release from the **Releases** section.
2. Open your Minecraft `FiskHeroes` heropacks folder.
3. Place the downloaded Heropack file inside the folder.
4. Launch Minecraft.
5. Select the character in-game.
